Guidance for Claude Code when working in this repository.

## Project coordination

This repository participates in a three-agent development workflow:

- **ChatGPT** — product architecture / UX / coordination
- **Claude Chat** — engineering and specification review
- **Claude Code** — implementation and repository verification

Shared coordination document:
**"Money Padel Prestige v3 — AI Project Ledger"**

Before beginning a substantial new task:

1. Read the Project Ledger where connector access is available.
2. Read Current Status.
3. Read Current Task.
4. Read Open Questions / Conflicts.
5. Read the latest three Handoff Log entries.
6. Then inspect the repository and `RATING_MODEL.md`.

Repository code/tests are authoritative for implementation reality.
`RATING_MODEL.md` is authoritative for rating methodology.
The Project Ledger is authoritative for coordination and product decisions.

If these conflict, **STOP and report the conflict. Do not guess.**

After completing substantial work, append/update the Project Ledger where
connector permissions allow it.

**Never overwrite another agent's historical handoff.**
